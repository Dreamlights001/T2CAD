# 课程演示脚本

建议顺序约 8–10 分钟，模型首次加载时间单独说明。

1. 启动 `python scripts/start.py`，打开打印的工作台地址；展示本地模型状态、前后端两个端口。
2. 打开“示例库”，运行“带颈法兰”。明确这是确定性工具链演示，不是大模型推理结果。
3. 点击左侧特征，观察法兰盘、凸台、中心孔、螺栓孔；播放底部建模过程，切换尺寸和线框。
4. 在参数页把中心孔由 24 改为 28，重新计算；在版本页回到先前版本。
5. 新建项目，输入 README 中的安装板需求，展示真实本地模型的规划、几何执行和保存事件。
6. 依次发送“孔径改为8mm”“厚度改为10mm”“长度改为120mm”，每次核对尺寸和版本。
7. 在参数页输入负孔径，展示几何校验失败和上次成功版本保留；恢复合法数值。自动纠错使用实测记录说明，不宣称每次模型都能修复。
8. 导出 STEP 并用 FreeCAD 打开；导出 Python 后运行 `python scripts/run_cad.py /绝对路径/model.py`，在 T2CAD-CAD 环境重建 STEP/STL/GLB。
9. 展示报告的架构图、流程图和验证表，说明精确 B-Rep 与显示网格的区别、模型能力边界和后续改进。

报告与答辩可以强调：大模型生成操作计划，确定性几何工具负责执行；几何校验通过不自动等于所有语义要求都满足。
